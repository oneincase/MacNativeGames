### 4.3 写 17 的 pass（黑场景 passdump，F3912）

```

```

- `140663` 是**最后一个**写 17 的 pass，前面几个 pass 的输出被它整体覆盖。
- `140663` 的 R 行资源列表**不含 17、不含 bloom 79/89**，只有 LUT/环境/别的小图 → 它是纯后处理合成。
- `c317`：把 `140663` 里 4 个 FS 输出改红 → 亮度 41.2 → 53.9（生效，但亮的是雾）。
- `c323`/`c328`/`c331`：改 `0ff2b337`/`140660`/`140661`/`140662` 的输出 → **全部无变化**（被 140663 覆盖）。

### 4.4 一个必须记住的教训

`0ff2b337` 改红无效**不是**因为改错变体：
- 旧链 v4 的 passdump 写的是 `-61f2c0938321_b`，v5 缓存里没有它；
- `NIER_SHADER_TRACE=1` 确认 v5 实际加载 `-8dd4c28170c6_b`（`len=47803`，改后变长）；
- 改它仍然无效 → **覆盖是真实的，不是工具误差**。

### 4.5 已经排除的假设

1. GS 未翻译（`137b54dc`）——SPIR-V 打通、GLSL 证明 passthrough、顶点直通，不是黑屏原因。
2. `early_fragment_tests`——移植完成（`85b74b5`，71 个 MSL 带上标志），但尼尔的 FS **全都**设这个标志，不构成差异。
3. bloom clamp / inf——已验证与亮度无关。
4. 立方体面合并（`TOTK_CUBE_MERGE=0`）——无变化。
5. 槽位纠正（`[slot-fix]` 触发）——无变化。
6. SSAO 黑、discard、雾层 alpha、`c2+0x160` 误报——都已逐个排除。

## 5. 下一步（按优先级）

### P0：确认 G-Buffer 到底谁写（最关键）

`24/25/26` 在 E16 里被判定「只输出 color(0) 的后处理 RT」，但 LUT 抓取又显示它们全 0。
两者矛盾，先解决这个矛盾：

1. 抓 `149537`–`149539`（clear）和 `149547`–`149549`（load）的完整绑定（`P` 行 + `B` 行 + `K` 行），
   确认**颜色附件数量**（`P c0` 到 `P c3` 有几条）。
2. 如果只有 `c0`，说明 MRT 后缀被截断 → 查 `rp_begin_ex` 的 `colorAttachments` 填充逻辑
   （`nvn_mtl.m:4542` 附近）与 NVN 侧 `nvnCommandBufferSetRenderTargets` 的附件数。
3. 如果 MRT 数量对，查几何 FS（`216aa095`/`fe25a5ab`）的 `[[color(N)]]` 输出——
   MSL 里是不是只有一个 `out.m_*` 结构。

### P1：如果 MRT 被截断，修渲染目标绑定

`rp_begin_ex` 里按 NVN 的 `nvnCommandBufferSetRenderTargets` 参数逐个绑 `colorAttachments[i]`，
确认循环上限用的是 `n` 而不是硬编码 1/4。

### P2：回到「为什么 17 是 0」

如果 MRT 正常，则 `0ff2b337` 的输出确实接近 0（不是被覆盖），
此时查 `_1795 = clamp(_631 × (1+_1777) × 8, 0, 1)` 里的 `_631 = sample(1057805E).y`——
但注意 `1057805E` 是场景 RT 自身（自采样），如果自采样读到的是 clear 值就恒为 0。

## 7. 陷阱清单（前人踩过的）

1. `pkill -f build/nier-native` 会杀掉自己的 shell → 用 `pkill -x nier-native` 或 `nier-nativ[e]`。
2. 多个跑批脚本并存会互相杀 → 启动前 `pkill -f "logs/c2[0-9][0-9].sh"`。
3. `texdump` 目录必须预先 `mkdir -p`，否则静默不写文件。
4. 清场不彻底 → `FAIL: reserve guest stack, heap and alias regions below 2^39`，要 `pkill -9 -x nier-native` 后 sleep ≥10 s。
5. `$WORK/build/shader-service/totk_xlate` 不会被自动更新 → 换翻译器后必须手动 `cp`。
6. 长等待后往 `.in` 追加命令不可靠 → 用 env（`DM_NVN_TEXDUMP`）或缩短等待。
7. `setsid` 在本机不存在 → 用 `nohup … & disown`。
8. 改 MSL 前先 `.bak`，`sed -i` 在 macOS 要 `-i ''`。
9. `find -exec rm -rf` 被安全网禁止 → 用 `rsync --exclude`。
10. 每轮截图必须用亮度量化（`/tmp/pngdark.py`、`/tmp/pngstat2.py`），不能只看"像不像"。
